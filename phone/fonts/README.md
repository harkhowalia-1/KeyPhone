# Fonts built into the phone

The phone's screen styles use these fonts. Latin subsets are embedded in
`phone/index.html` so they work offline. Each is licensed under the SIL Open
Font License 1.1; the licence texts are in this folder.

| Used for | Font | Source |
|---|---|---|
| Mono (backlit LCD) | Jersey 10 | Google Fonts |
| Flip | Nunito | Google Fonts |
| Modern Bar | Inter | Google Fonts |
| Slim | Titillium Web | Google Fonts |
