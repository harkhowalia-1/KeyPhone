What's real

Every key does something.

The phone hands real work to the device it runs on. Nothing here is a mock-up.

Real calls

Dial on the keypad and press the green key. iPhone places the call; on a Mac it goes through FaceTime or your iPhone. Call length lands in the Log.

Call key

Text messages

Write with multi-tap or predictive text, then send through iOS Messages or the Mac Messages app. Sent items are kept on the phone.

Menu › Messaging

Your contacts

Names is your device's address book. Add, edit or delete a name and the change is made in Contacts too.

Right key › Names

Camera, Gallery and Recorder

Take photos and videos with a live viewfinder on the phone's screen. The Gallery is your real Photos library, and the Recorder records voice memos.

Menu › Media

Alarms that ring

Alarm clock, calendar reminders and the countdown timer become system notifications, so they go off even when the app is closed.

Menu › Organiser

Java games and the web

Java ME .jar games run on the phone's own screen with the keypad as controls, and the browser opens real websites in mobile layout.

Install

Two downloads, one phone.

The apps are built from this repository's source on GitHub's servers every time a new version is tagged.

Mac

macOS 13 Ventura or later · Apple silicon and Intel
  1. Download LarchK7.dmg and open it.
  2. Drag Larch K7 onto Applications in the window that appears.
  3. Open it from Applications. The first time, macOS says it can't check the developer. Open System Settings › Privacy & Security, scroll down and click Open Anyway.
If macOS says the app is damaged, run this once in Terminal, then open it again:
xattr -dr com.apple.quarantine "/Applications/Larch K7.app"

iPhone

iOS 16 or later · free Apple ID
  1. Download LarchK7.ipa on your Mac or PC.
  2. Install it with a sideloading tool such as Sideloadly or AltStore. Connect your iPhone, choose the .ipa and sign in with your Apple ID.
  3. Trust the app on the iPhone: Settings › General › VPN & Device Management, then turn on Developer Mode if iOS asks.
With a free Apple ID, iOS stops opening sideloaded apps after 7 days. Reinstall with the same tool to renew; your phone's contacts and settings are kept.
Straight answers

What it can't do.

Some things are walled off by Apple, so the phone says so instead of pretending.

  • Reading textsiOS and macOS don't let apps read your messages. The Inbox holds what's saved on this phone.
  • Call historyThe Log lists calls made from Larch K7, not every call on the device.
  • Signal strengthOn iPhone the bars show online or offline. On a Mac they follow your Wi-Fi strength.
  • Java start-upThe Java runtime loads from the internet when an app starts, so Java games need a connection.
  • Websites in the web versionIn the browser version some sites refuse to show inside the phone; the Mac and iPhone apps show every site.
  • FM radioMac and iPhone have no FM receiver, so the Radio says so when you open it.
Build it yourself

Open source, built in the open.

The phone is one HTML file. The Mac and iPhone apps wrap it and connect it to the system. On a Mac with Xcode:

# get the code
git clone https://github.com/__REPO__.git
cd larch-k7/apple
# needs Homebrew
brew install xcodegen
./make_web.sh && xcodegen generate
open Larch.xcodeproj
